# 実装計画

一般公開は 2026年6月末を目標にする。  
7月の高校野球予選シーズンで、ベータ版として実用できる状態を目指す。

## 進め方

- まずは球場で使ってもデータが消えない状態を作る。
- 次に、入力とスコアブック表示のズレを減らす。
- その後、取り込み・書き出し・PDF・PWAを整える。
- 慶応式、クラウド共有、課金、AI APIは土台が固まってから進める。

## Phase 1: 保存JSONとローカル保存

状態: 完了（2026-05-14）  
以後は不具合や互換性問題が見つかった時に随時補修する。

最優先。  
これができると、球場での試用、後から編集、PDF、慶応式展開が進めやすくなる。

実装内容:

- `schemaVersion` と `appVersion` を含む保存JSONを作る。
- 現在の試合状態を `localStorage` に自動保存する。
- ページ再読み込み後に試合を復元する。
- JSONエクスポート / インポートを実装する。
- 既存の `state` と保存JSONの対応表を作る。

完了条件:

- ブラウザを閉じても試合が残る。
- JSONファイルでバックアップできる。
- 保存データに `schemaVersion: 1` と `appVersion` が入る。

## Phase 3: 入力UI整理

手動詳細入力を廃止し、標準入力に集約する。

## Phase 4: インポートと自然文入力の整理

### 日刊スポーツ取り込み

目的:

- 終了済み、または進行中の試合について、日刊スポーツの表をまとめて取り込む。
- 1打席ずつではなく、複数イニング分をまとめてスコアブック化する。
- 途中経過でも取り込めるようにする。

実装内容:

- 日刊スポーツ取り込みを全画面UIにする。
- `先攻チーム取り込み`、`内容クリア`、`後攻チーム取り込み` に整理する。
- 選択打順からの一括取り込みは廃止し、原則として1番から自動配置する。
- 選手名は3段の名前欄に分けて反映する。
- 4人目以降は暫定的に3段目へ `/` 区切りで表示する。
- 複数イニングのアウトカウント、標準進塁、得点をラフに推定する。
- `ギ`、`邪`、`野`、`併` などの略記を解釈する。
- インターネットブラウザ、iPhoneブラウザの両方のコピペ形式に対応する。

完了条件:

- 日刊スポーツの表をコピペして、大まかなスコアブックを作れる。
- 先攻と後攻を分けて取り込める。
- 多少の誤りがあっても、後から編集で直せる。

### X / Twitter 取り込み

目的:

- 観戦者のXポストや実況メモを、1イニング単位で取り込む。
- 結果だけでなく、原文コメントも吹き出しとして残す。

実装内容:

- X取り込みを全画面UIにする。
- 1回の取り込みは1イニングに制限する。
- 複数イニングが含まれている場合は警告する。
- 前回取り込みの続きから配置することをデフォルトにする。
- 取り込み結果には原文コメントを吹き出しとして保存する。
- `一塁はセーフ`、`牽制アウト`、`暴投で進塁`、`挟殺` などの表現を段階的に強化する。
- 解釈困難な行は、コメント付きの下書きとして残す。

完了条件:

- 1イニング分のXポストを貼り付けて、打順に沿った下書きが作れる。
- 各セルに原文コメントの吹き出しが付く。
- 誤変換があっても、後から修正しやすい。

### 1人単位の自然文入力

目的:

- 従来の `詳細入力` の代替として、1打席だけ自然文で入力する。
- 将来の音声入力の受け皿にする。

実装内容:

- X取り込み画面の近くに `1打席入力` として配置する。
- 現在打者、または選択した過去セルに対して反映できるようにする。
- 例: `ショートゴロ内野安打`、`センター前ヒット`、`見逃し三振`。
- 常時表示のテキスト入力欄は廃止し、必要な時だけ使うオプションにする。

完了条件:

- 1人分だけ自然文で入力し、現在セルまたは選択セルへ反映できる。
- 通常のボタン入力と役割が混ざらない。

### AI整形プロンプト生成

目的:

- ユーザー自身がChatGPT、Gemini、Grokなどに貼り付けて、このアプリに取り込みやすい形式へ変換できるようにする。
- 将来のAPI連携、ローカルAI化、改善データ収集につなげる。

実装内容:

- AI整形プロンプト生成を改善する。
- 日刊スポーツ用、X 1イニング用、1打席用でプロンプトを分ける。
- `名前 結果 コメント` を1打者1行で出力するよう明示する。
- 出力例は匿名化する。
- 必要に応じて、整形結果の貼り付け先へ誘導する。

完了条件:

- 取り込み前にAI整形プロンプトを生成できる。
- 複数AIで破綻しにくい、明示的なプロンプトになっている。
