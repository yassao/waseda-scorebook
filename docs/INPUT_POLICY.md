# 入力方針

Scorebook by CuViu の入力UIは、球場で素早く記録できることを最優先にする。

## 基本方針

- 通常入力は、ボタン・フリック・プレビュー操作を主役にする。
- テキスト入力は補助機能として扱い、常時の主役にはしない。
- 入力結果はできるだけリアルタイムにプレビューとスコアブックへ反映する。
- 確定操作は「保存」よりも「次の打者に移る」と考える。
- 誤入力に備えて、Undo / Redo と後から編集できる仕組みを重視する。

## 入力の種類

### 打者結果

現在打者の打撃結果を入力する。

主な分類:

- 安打
- 二塁打
- 三塁打
- 本塁打
- 四球
- 死球
- 三振
- 犠打
- 犠飛
- ゴロアウト
- フライアウト
- ライナーアウト
- 失策出塁
- 封殺 & FC
- 併殺
- その他

打球方向や野手連携は、数字ボタンで入力する。

例:

- `8`: 中堅手方向
- `5`: 三塁手方向
- `463`: 二塁手から遊撃手、一塁手への連携
- `123`: 投手から捕手、一塁手への連携

ハイフンは入力しなくても、内部では `4-6-3` のように解釈できるようにする。

### 走者結果

打者以外の走者の動きを入力する。

走者結果は「一走」「二走」「三走」ごとに対象を切り替える。  
対象走者が存在しない場合は非活性にする。

基本の考え方:

- 標準進塁はアプリが自動推定する。
- 標準と違う動きがある場合だけ、走者結果から修正する。
- 到達塁は「最終到達塁」として入力する。
- 理由は「打球」「盗塁」「暴投」「捕逸」「失策」「アウト」などを選ぶ。

例:

- 一走が打者安打で三塁へ進む: 一走を選び、最終到達塁を `3` にする。
- 一走が盗塁で二塁へ進む: 一走を選び、理由を盗塁、最終到達塁を `2` にする。
- 三走が暴投で生還: 三走を選び、理由を暴投、最終到達塁を本塁にする。
- 一走が二塁封殺: 一走を選び、アウト、連携を入力する。

## 自然文入力

自然文入力は常時表示ではなく、オプション機能に寄せる。

### 1打席入力

現在打者に対して、1打席分だけ自然文で入力する。

例:

- `ショートゴロ内野安打`
- `センター前ヒット`
- `見逃し三振`
- `ライトオーバー二塁打`
- `一塁ランナー三塁へ`

将来の音声入力は、この1打席入力に統合する。

### 1イニング入力

Xポストや観戦メモを、1イニング単位で取り込む。

原則:

- 1回の取り込みは1イニングだけに制限する。
- 1行1打者を推奨する。
- コメントは吹き出しとして保存する。
- 解釈が曖昧なものは下書きとして反映し、後から修正できるようにする。

例:

```text
山田　中安　低いライナー
佐藤　空三振　外角低め
鈴木　463併殺　一塁はセーフ
```

### 日刊スポーツ取り込み

日刊スポーツの打撃成績表を貼り付けて一括反映する。

原則:

- 先攻チーム取り込み
- 内容クリア
- 後攻チーム取り込み

の流れにする。

## AI整形

初期段階では、アプリ内AIではなくプロンプト生成を使う。

目的:

- Xポストや観戦メモを `名前 結果 コメント` の形式に整える。
- ユーザーが自分のAIに貼り付けて変換できるようにする。
- 将来のAPI活用やローカルAI化に向けて、失敗例を蓄積する。

推奨フォーマット:

```text
[名前] [打撃結果] [コメント]
```

1打者ごとに必ず改行する。

匿名化された例:

```text
選手A　右安　低いライナー
選手B　空三振　外角変化球
選手C　四球　満塁
```

## つぶやき

つぶやきは、打席や走者イベントに紐づくコメントとして扱う。

- 改行を含めて保存できる。
- 登録は送信ボタンで行い、Enterだけでは登録しない。
- 対象は「現在打者」または「選択した過去セル」とする。
- スコアブック上には小さな吹き出しを表示する。
- 吹き出しをタップすると内容を確認・修正できる。

## 後から編集

スコアブックは後から修正できる必要がある。

想定例:

- エラーがヒットに訂正される。
- 安打が失策に訂正される。
- 走者の進塁先が後から判明する。
- コメントを追記する。

過去セルをタップした場合は、以下を選べるようにする。

- 打者結果を編集
- 走者結果を編集
- つぶやきを編集

## 今後の検討

- 打者結果と走者結果のリアルタイム反映をさらに安定させる。
- 走者GUIを野球盤型に近づける。
- 1打席入力と1イニング入力の境界をユーザーにわかりやすくする。
- AI整形の成功・失敗を、ユーザー同意のもと改善データとして活用する。
