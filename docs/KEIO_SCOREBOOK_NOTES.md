# 慶応式 / NPB式スコアブック 実験メモ

作成日: 2026-06-10
最終照合日: 2026-09-08

## 目的

早稲田式の入力データを壊さず、表示だけを慶応式 / NPB式へ切り替えられる実験モードを作る。
開発者が先に試し、8割程度使える状態になったら限定的にユーザーへ開放してFBをもらう。

## 主資料

- NPB公式 `NPB式スコアブックの記入方法`
  - https://npb.jp/scoring/scoring_howto.pdf
- NPB公式スコアリングページ
  - https://npb.jp/scoring/

## 初期方針（実験開始時）

- 保存JSONと入力ロジックは早稲田式と共通にする。
- `state.scorebookStyle` を `waseda` / `keio` で切り替える。
- 慶応式はまず画面上のセル表示だけを差し替える。
- PDF出力、集計欄、詳細な公式記録ロジックは早稲田式のままにして、表示実験のFBを優先する。
- UIに通常の設定項目は出さず、隠しコマンドで切り替える。

## 隠し切替

- URLに `?style=keio` または `?scorebook=keio` を付ける。
- 画面上部のバージョン表示を7回タップする。
- 慶応式中はヘッダーに `慶応式 実験中` を表示する。

## 初期実装範囲

- 空セルも慶応式風のセル枠に切り替える。
- 打席結果は慶応式寄りの短い記号に変換する。
  - 三振: `SO`
  - 振り逃げ: `K`
  - 四球: `BB`
  - 死球: `D`
  - 犠打: 送球順や処理結果を四角で囲む
  - 犠飛: `F` + 守備番号を四角で囲む
  - 本塁打: `HR`
  - 併殺: `DP`
  - フライ: `F` + 守備番号
  - ファウルフライ: `FF` + 守備番号
  - ライナー: `L` + 守備番号
  - ゴロアウト: `6-3` など送球順を数字で表示
- 入力結果、走者イベント、一言メモ、保存JSONは既存データを利用する。

## 自動運転時の優先順

1. 公式資料と明らかに違う早稲田式の残骸を消す。
2. 打席結果の記号をNPB式に近づける。
3. 走者アウト・進塁・得点の記入位置を整理する。
4. 投手交代・代打・代走など、試合進行の記録へ広げる。
5. 最後にPDF出力へ反映する。

## 未実装・要検証

- NPB式の細かな投球欄・走者欄・失策欄の正式配置。
- NPB式ロスター欄、交代線、集計欄の完全準拠。
- 自責点、投手責任、公式記録向けの詳細集計。
- 代打・代走・守備変更のNPB式表記。
- 早稲田式と慶応式の同一打席データからの完全な相互表示。

## ユーザー開放の目安

- 主要結果（安打、二塁打、本塁打、三振、四球、犠打、犠飛、併殺）が慶応式表示で大きく破綻しない。
- 早稲田式に戻してもデータが変わらない。
- 保存・復元・試合データ書き出しで表示モードが保持される。
- 実験中であることが画面上で明確に分かる。
