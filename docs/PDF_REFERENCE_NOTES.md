# 長崎県高野連スコアブック資料メモ

`score-book-.pdf` を基準資料として、今後の実装で優先して合わせる項目を整理する。

## 紙面上部の記入項目

- 大会名
- 年月日
- 球場
- 球場状態
- 天候・風向
- 観衆
- 開始時刻
- 終了時刻
- 所要時間
- 一塁側チーム
- 三塁側チーム
- 審判員: 球審、一塁、二塁、三塁
- 放送
- 記録者

## 打順欄

- 打順
- 選手名
- 背番号
- 先発守備位置
- 打ち方
- 交代選手
- シート変更
- 交代時期を示す縦波線

## スコアボックスの基本

- 右下: 打席で行われたプレイ
- 左回り: 走者の進塁
- 中央ダイヤ: アウトカウント、得点、残塁
- 2個以上の進塁: 矢印で示し、到達マスに状況を書く
- 打席マスは可能な限り空欄にせず、アウト・得点・残塁などを記す

## 投球欄

| 内容 | 記号 |
|---|---|
| 見逃しストライク | `○` |
| 空振りストライク | `×` |
| ファウル | `－` |
| ボール | `・` |
| バント失敗ストライク | `ギ` またはバント記号 |

投球数はイニングごとの数と合計数を残せるようにする。

## 色ルール

- 赤: 安打の斜線、盗塁、重盗、得点、打点者の打順など
- 青: 四球、死球、犠打、犠飛、失策、暴投、捕逸、ボークなど
- 黒: 通常のアウト、守備連携、投球記号など

## 打撃・走塁記号

- 四球: `B`
- 遠四球: `B'`
- 死球: `DB`
- 犠打: 青の四角囲み
- 犠飛: 青の三角囲み
- 三振: `K`
- 空振り三振: `K` を丸囲み
- 振り逃げ: 反転 `K` または `K'`
- 盗塁: `S`
- 重盗: `DS`
- 盗塁死: 送球連携 + `T`
- フィルダースチョイス: `FC`
- 打撃妨害・守備妨害: `IF` / `IP`
- 走塁妨害: `OB`
- ボーク: `BK`
- 暴投: `WP`
- 捕逸: `PB`

- 打席

## 実装メモ

- 表示は早稲田式を主軸にしつつ、保存JSONは表示方式に依存させない。
- PDF出力時は、この資料の紙面項目を埋められるJSON構造を優先する。
- 旧実装の記号は互換読み込みし、新規入力・新規描画を段階的に資料準拠へ寄せる。
